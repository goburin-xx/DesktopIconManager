# 🖥️ DTアイコン 1発管理 for Windows

**配信・画面共有で「見せたいアイコン」だけ残す選択非表示ツール**

Windowsのデスクトップ上にある各種アイコン（ショートカット、ファイル、PCやごみ箱などのシステムアイコン）の表示・非表示をワンクリックで手軽に切り替え・管理できるWindows向けツールです。

動画配信やオンライン会議、プレゼン時の画面共有で、「個人情報や見せたくないファイルを一時的に隠したい」「特定のアプリのアイコンだけを残してデスクトップをスッキリ見せたい」といったシーンに活用できます。

---

## 💡 主な特徴

- **個別選択による柔軟な非表示設定**  
  デスクトップ上のアイコンを一覧取得し、チェックを入れた項目だけをまとめて「非表示（隠しファイル属性）」または「再表示」に切り替えられます。
- **一括非表示 / 一括再表示**  
  「全アイコンを非表示」「全アイコンを再表示」ボタンにより、一発でデスクトップをクリーンな状態にできます。
- **システムアイコンの個別制御**  
  PC（コンピューター）、ごみ箱、コントロールパネル、ネットワーク、ユーザーファイルなどのWindows標準システムアイコンの表示状態をレジストリ経由でダイレクトにコントロールします。
- **簡単な操作性**  
  リストの行をクリックするだけでチェックボックスをON/OFFできる直感的なUIデザインを採用しています。

## 📸 スクリーンショット

### 1. 一般のデスクトップアイコン管理画面

デスクトップ上のファイルやショートカットを一括・個別で選択し、非表示属性の切り替えが行えます。

![一般アイコン管理](docs/images/main1.png)

### 2. システムアイコン管理画面

PC、ごみ箱、コントロールパネルなどの標準システムアイコンの表示状態を制御します。

![システムアイコン管理](docs/images/main2.png)

### 3. 部分非表示（見せたいアイコンだけを残す）

指定したアイコンだけを残して非表示に設定した状態です。配信・画面共有時に最適なデスクトップ環境を作れます。

![部分非表示の様子](docs/images/partlu-hidden.png)

### 4. 全アイコン非表示（デスクトップの完全クリーン化）

すべてのアイコンを一括非表示にし、壁紙だけのクリーンな状態へ瞬時に切り替えられます。

![全非表示の様子](docs/images/all-hidden.png)

### 5. Windows標準「デスクトップアイコンの設定」との連動

本アプリでのシステムアイコン設定は、Windows標準の設定（`desk.cpl`）とも相互に整合性を保ちながら動作します。

![Windows標準設定画面](docs/images/sistem.png)

## 🚀 ダウンロードと使い方
 [GitHubのリリースページ](https://github.com/goburin-xx/DesktopIconManager/releases/tag/v1.0.0) から、用途に合った配布形式をダウンロードしてください。
### 単体EXE版（おすすめ）
1. DesktopIconManager_v1.0.0.exe をダウンロードします。
2. デスクトップなど好きな場所に置き、ダブルクリックして起動します。
3. この版はEXEファイル単体で動作します。
### ZIP版
1. DesktopIconManager_v1.0.0.zip をダウンロードします。
2. ZIPファイルを解凍（展開）します。
3. 展開したフォルダ内の icon_manager.exe をダブルクリックして起動します。
4. icon_manager.exe だけをフォルダの外へ移動しないでください。必要なファイルやフォルダ構成を維持してください。
### アプリの操作
- 「一般のデスクトップアイコン」タブ
  - 隠したいアイコンにチェックを入れ、「チェックした項目を非表示にする」をクリックします。
  - 再び表示させたい場合は、「チェックした項目を再表示する」をクリックします。
- 「システムアイコン」タブ
  - ごみ箱やPCなどのアイコンの表示状態を選択し、非表示/表示の切り替えを行います。
### 💡 補足ヒント
非表示にしたアイコンがデスクトップ上で「半透明」で残って表示される場合は、Windowsのエクスプローラー設定で「隠しファイルを表示しない」に設定してください。

## 🛡️ 安全性とプライバシーについて
- 本ツールはWindows標準のファイル属性（隠し属性）および公式レジストリキーのみを使用して動作します。
- 外部への通信機能や個人情報の収集機能は一切含まれておりません。
- GitHub上でソースコードを完全公開しているオープンソースソフトウェアです。
- 実行ファイルの誤検知について
  本ツールの実行ファイル（icon_manager.exe）は Python および PyInstaller を用いてビルドされています。そのため、一部のアンチウイルスソフトや機械学習エンジンにおいて、構造上の理由から「誤検知（False Positive）」が発生する場合があります。公開前にVirusTotalで検査を実施しています。主要なセキュリティソフト（Microsoft Defender等）では安全（クリーン）判定を確認しております。（心配な場合は VirusTotal 等でスキャンしてご確認いただけます）
## ⚙️ 動作環境
- 対応OS： Windows 10 / Windows 11
- 実行形式： 単体EXE版（DesktopIconManager_v1.0.0.exe）、ZIP版（展開後のフォルダ内で icon_manager.exe を実行）
